## 3. Constraints and rules

Repo and submission
- One public repo, only branch `main` (must be default branch or link `/tree/main`). Submit one link.
- No other links inside the repo or README. No images, screenshots, PDFs, slides, video, audio.
- README line 1 exactly `Domain: E-commerce`. Section order fixed (see above). `## How to run` lists exact commands from a clean clone, including `pip install -r requirements.txt`.
- `requirements.txt`: `numpy==<version used>` plus a pinned line per extra package. Python >= 3.10.
- Scripts must run top to bottom on a clean clone and regenerate exactly the committed `outputs/`. Helper file shared by Part 2 and 4 must not re-run a Part on import.

Forbidden
- No ready-made logistic regression, KNN, k-means, PCA or metric routines for graded numbers; no polyfit, cov, corrcoef, lstsq. Allowed: NumPy arithmetic, `numpy.linalg.solve`, `numpy.linalg.eigh`, stable argsort.
- Never type a reference or checkpoint value; that line scores zero.
- No test-row leakage (fit, standardise, choose K or tau on train only). No recomputing mean/SD inside CV folds. No training of Models A/B.
- No dollar sign for money; use `INR 400` or `400 Rupees`. Do not edit `generate_data.py` or hand-edit the CSV.
- Original work; author must be able to explain every line.

Conventions that decide numbers
- Sample SD (n-1) everywhere unless stated; ln natural; positive means p >= tau.
- Output format: `key = value`, floats 4 dp, ints plain, booleans `yes`/`no`; CSV exact headers, floats 4 dp.
- Tolerances: max(0.005, 0.0005*|ref|); confusion cells +/-1; money +/-INR 450; `cost_tau` exact; `gd_slope_gap` < 0.001; counts and text exact; other documented exceptions in the brief.

Dates
- Window 6 to 16 Nov 2026; submit before the closing time on the course platform. Today is 14 Nov 2026, so 2 days remain (see schedule risk).
